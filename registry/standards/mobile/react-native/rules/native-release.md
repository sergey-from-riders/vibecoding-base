# Мобильный релиз

## Коротко

Изменение нативных возможностей требует соответствующей сборки приложения.

## Плохо

```text
Новый нативный модуль доставлен только JavaScript-обновлением.
```

## Хорошо

```text
JS-обновление совместимо с установленным runtime.
Нативные изменения включены в новую сборку.
```

## Почему

Установленное приложение не сможет вызвать отсутствующий нативный код.

## Когда применять

Пример механизма совместимости — runtimeVersion в Expo EAS Update. OTA разрешён только в пределах политики магазина и выбранного механизма обновлений. Версии React и RN должны быть совместимы.

## Как проверить

- Проверьте запуск, авторизацию и возврат на предыдущую совместимую версию.

## Человек

Выбирает поддерживаемые версии клиента и порядок распространения.

## Агент

Реализует поведение клиента и проверяет потерю сети, повторный запуск и ограничения платформы.

Контроль результата:

- Проверьте запуск, авторизацию и возврат на предыдущую совместимую версию.
