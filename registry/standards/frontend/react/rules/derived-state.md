# Производное состояние

## Коротко

Если значение полностью определяется текущими данными, вычислите его при отображении.

## Плохо

```javascript
useEffect(() => setFullName(first + " " + last), [first, last]);
```

## Хорошо

```javascript
const fullName = first + " " + last;
```

## Почему

Лишняя копия состояния требует синхронизации и создаёт промежуточные неверные значения.

## Когда применять

Effect нужен для синхронизации с внешней системой. Тяжёлое вычисление оптимизируйте после измерения.

## Как проверить

- Не хранится ли одна информация в нескольких состояниях?

## Человек

Определяет исходные данные и правила вычисления результата.

## Агент

Реализует поведение компонентов и проверяет изменение данных, загрузку и ошибку в браузере.

Контроль результата:

- Не хранится ли одна информация в нескольких состояниях?

## Пример применения

Корзина хранит позиции и количество; итог вычисляется при рендере из этих данных. Человек задаёт правила скидки, агент проверяет изменение количества и серверный перерасчёт перед оплатой.
