## Содержательная ревизия

Уточнены все 11 правил по PostgreSQL 18: типы и SQL naming, NULL/constraints, composite foreign keys, конкурентная запись, expand/contract миграции, индексы, UTC/локальные расписания, JSONB, удаление и точная денежная арифметика. Начальный профиль составлен из существующих ID без дублирующей статьи.

Проверка текстов и первичных источников выполнена 2026-11-13. Это дата ревью, а не заявление о дате публикации или о прохождении проверок приложением. Решение по каждому замечанию исходного аудита и фактически выполненные проверки примеров записаны в [реестре ревизии](../../../../docs/revision-2026-11-13/backend.md).

## Зависимости и область применения

Прежний манифест связывал модуль со следующими требованиями:

- [Безопасность](../../security/no-secrets/standard.md), исторический диапазон `^2.1.0`.

Диапазоны сохранены для истории. В документационной модели они не разрешаются автоматически; для применения фиксируйте один точный commit корпуса и выбранные ID. Условия конкретного правила имеют значение независимо от включения всего модуля.

## Начальный профиль PostgreSQL

Для нового приложения сначала выберите поддерживаемую версию PostgreSQL и драйвер, владельца схемы/миграций и воспроизводимый способ создания тестовой базы. Примеры этой ревизии проверены по документации PostgreSQL 18; наличие конкретной функции, например `uuidv7()`, нельзя переносить на старые версии без проверки.

| Начальное решение | Применимое правило |
| --- | --- |
| Неквотированные `lower_snake_case`, смысл единиц и допустимые имена | [database.naming](rules/naming.md) |
| Первичные ключи, обязательность значения и уникальность | [database.identifiers](rules/identifiers.md), [database.constraints](rules/constraints.md) |
| Ссылки между таблицами и tenant scope | [database.foreign-keys](rules/foreign-keys.md) |
| Атомарная бизнес-операция, конкуренция и безопасное изменение схемы | [database.transactions](rules/transactions.md), [database.migrations](rules/migrations.md) |
| Моменты времени и отдельно локальные расписания | [database.time-money](rules/time-money.md) |
| Деньги, JSONB, индексы и удаление при наличии соответствующей задачи | [database.money](rules/money.md), [database.jsonb](rules/jsonb.md), [database.indexes](rules/indexes.md), [database.history-delete](rules/history-delete.md) |

Это навигационный профиль, а не дополнительное правило. Правила backups/restore, доступа и эксплуатации выбираются отдельно по риску и архитектуре; наличие схемы не доказывает готовность базы к эксплуатации.
