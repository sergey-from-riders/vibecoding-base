# Обработка ошибок

## Коротко

Не превращайте ошибку зависимости в успех. Сохраняйте причину, которую должен различать вызывающий код, и отдельно отображайте ее в безопасный внешний контракт.

## Плохо

```go
func persist(save func() error) error {
    _ = save()
    return nil
}
```

## Хорошо

```go
func persist(save func() error) error {
    if err := save(); err != nil {
        return fmt.Errorf("save order: %w", err)
    }
    return nil
}
```

## Почему

Фрагмент Go требует import fmt. %w сохраняет цепочку для errors.Is/As; сравнение текстов err.Error() хрупко. Оборачивание чужого типа делает его наблюдаемой частью API пакета, поэтому на устойчивой границе может потребоваться преобразование в собственную доменную ошибку, а не раскрытие деталей драйвера.

## Когда применять

Для Go с errors.Is/As и %w (с Go 1.13). Ожидаемые неверный ввод, конфликт и отсутствие объекта возвращаются как error, а не panic. На HTTP-границе сопоставляйте известные доменные ошибки с документированными статусами; неизвестная внутренняя ошибка не раскрывает SQL, пути или credentials.

Отдельно различайте context.Canceled и context.DeadlineExceeded через errors.Is: отмена запроса не должна выдаваться за успех или автоматически классифицироваться как авария БД. Выберите одно место итогового журналирования: нижние слои добавляют контекст, внешний обработчик фиксирует итог без многократного одинакового лога. Успех допускает nil только при выполненном контракте; игнорирование ошибки допустимо лишь при явно необязательном эффекте с установленной обработкой/наблюдаемостью.

## Как проверить

1. save вернул nil → persist → nil → результат unit-проверки.

2. save вернул sentinel → persist → errors.Is на sentinel истинно, HTTP не успешный → цепочка ошибки и ответ адаптера.

3. Вложенная отмена или ошибка с секретом в тексте → граница → отмена распознана, клиент/лог не получает секрет, итог не продублирован каждым слоем → контроль ответа и логов.

## Человек

Выбирает стабильные доменные причины и безопасное представление ошибок.

## Агент

Проверяет все возвращаемые error, сохраняет нужную цепочку и классифицирует Is/As; проверяет отсутствие ложного успеха и утечки.
