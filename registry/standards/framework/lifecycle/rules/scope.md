# Границы задачи

## Коротко

До существенной работы сформулируй результат, что входит/не входит, ограничения, предположения и наблюдаемую приемку.

## Плохо

```text
«Сделать счета».
Готовность: есть экран; доступ, сохранение и границы задачи неизвестны.
```

## Хорошо

```text
SPEC-4: пользователь открывает собственный сохраненный счет.
Входит: чтение и проверка доступа; не входит: выпуск и оплата счета.
AC-4.1: собственный ID → счет с сохраненной суммой.
AC-4.2: чужой ID → нет раскрытия данных.
Допущение: счета уже создаются существующим процессом.
Новое требование оплаты: отдельная оценка области, не скрытая добавка.
```

## Почему

Проверяемая область ограничивает лишнюю реализацию и позволяет отличить незавершенную задачу от нового требования.

## Когда применять

Для новых функций и неоднозначных изменений. Для ясного небольшого исправления достаточно нескольких предложений и регрессии; Spec Kit/OpenSpec/BMad показывают варианты процесса, но не требуют всех своих артефактов для каждой задачи.

### Подробные условия

Для затронутого поведения задай хотя бы нормальный и существенный отрицательный сценарий; граничные случаи выбираются по риску. Свяжи важные требования с устойчивыми метками, чтобы план и проверка не потеряли их.

Новое существенное требование оценивается по влиянию на цель, стоимость, сроки и полномочия. Обнови область и приемку; запроси решение только там, где изменение выходит за действующее поручение. Обычный выбор реализации в его рамках не требует нового согласования.

## Как проверить

- Исходная задача → сопоставить diff с приемкой → каждый существенный результат относится к объявленной области.
- Чужой объект → пройти отрицательную приемку → данные недоступны, а не просто скрыты в UI.
- Появилась новая функция → оценить влияние → область явно обновлена либо функция оставлена вне текущей работы.

## Человек

Определяет нужный результат и существенные ограничения, не предписывая необоснованные слои.

## Агент

Сохраняет связь требования и приемки; сообщает об изменении области, продолжая работу в уже разрешенной части.
