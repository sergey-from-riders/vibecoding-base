# Вертикальный сценарий

## Коротко

Первый рабочий результат должен завершать один полезный сценарий через нужные границы: вход, право доступа, обработку, сохранение и повторное чтение, если они входят в задачу.

## Плохо

```text
Есть двадцать пустых endpoint и экран с локальным массивом.
Результат назван работающей системой сохранения заказов.
```

## Хорошо

```text
Сценарий: создать один заказ → записать → открыть заново по ID.
Права: другой пользователь его не читает.
Ошибка записи: UI сохраняет ввод и показывает неуспех.
Если используется mock: результат помечен прототипом, интеграция not-run.
Миграция: совместимые шаги с проверкой старого и нового клиента.
```

## Почему

Завершенный сценарий обнаруживает ошибки на стыках компонентов раньше, чем множество отдельно существующих заготовок.

## Когда применять

Для постепенной реализации продукта. Исследовательская задача может завершаться измерением или решением, без кода. Для необратимой миграции отдельно планируются восстановление и совместимость; «маленький шаг» сам по себе не делает ее безопасной.

### Подробные условия

Обработай существенную ошибку, чтобы пользователь не получал ложное сообщение об успехе. Не добавляй слой, который не нужен этому сценарию.

Прототип с mock или исследование допустимы, если именно это цель и ограничения явно названы. Они не подтверждают интеграцию с реальной зависимостью. Сквозное изменение дели на совместимые этапы: сначала поддержка нового контракта с переходным чтением, затем переключение потребителей и только после него удаление старого поведения.

## Как проверить

- Сохранение заявлено → создать и заново открыть объект → реальные данные сохранились в нужной среде.
- Запись отклонена → повторить сценарий → нет ложного успеха, ввод доступен для исправления/повтора.
- Интеграция заменена mock → оценить результат → явно указан прототип; сквозная готовность не заявлена.

## Человек

Выбирает минимальный полезный сценарий и решает, нужен рабочий результат или исследование.

## Агент

Проверяет весь объявленный путь, отмечает заглушки и поддерживает совместимые промежуточные состояния.
