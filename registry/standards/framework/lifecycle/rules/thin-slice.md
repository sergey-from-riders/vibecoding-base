# Вертикальный сценарий

## Коротко

Связывайте интерфейс, данные и проверки небольшими законченными изменениями.

## Плохо

```text
20 пустых обработчиков.
Ни один сценарий не работает.
```

## Хорошо

```text
Один запрос → проверка доступа → данные → ответ.
Есть проверка результата.
```

## Почему

Так ошибки взаимодействия обнаруживаются раньше.

## Когда применять

Это инженерное правило справочника, а не требование протокола. Первоисточник описывает подход или механизм; конкретный процесс выбирается проектом.

Рекомендация для продуктовой разработки; отдельное исследование может не иметь рабочего интерфейса.

## Как проверить

- Можно ли показать завершённый пользовательский сценарий?

## Человек

Выбирает минимальный полезный сценарий для первого выпуска.

## Агент

Изучает существующий код, предлагает минимальное решение и связывает изменения с критериями приёмки.

Контроль результата:

- Можно ли показать завершённый пользовательский сценарий?
