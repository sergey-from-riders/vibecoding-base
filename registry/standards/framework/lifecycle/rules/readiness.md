# Критерии готовности

## Коротко

Готовность объявляется для конкретного результата, версии и среды по выполненным критериям приемки.

## Плохо

```text
Markdown сформирован и JSON валиден.
Вывод: стандарт принят, сайт опубликован, приложение соответствует.
```

## Хорошо

```text
Содержание: уточнено и проверено по источникам, revision C.
Формат: схема проверена для C.
Публикация: not-run; активный commit сайта не подтвержден.
Проект-потребитель: соответствие не проверялось.
Выпуск возможен после его собственных приемочных критериев.
```

## Почему

Раздельные состояния не позволяют превратить готовый текст или работающий шаблон в недоказанное заявление о работающей системе.

## Когда применять

Для feature, документации, релиза и проекта. Набор стадий выбирается по задаче: опечатке не нужны production-проверки. Для справочника отдельно проверяются содержание, импортируемый формат и фактическая опубликованная ревизия.

### Подробные условия

Разделяй состояние содержания/спецификации, реализации, проверок и публикации; одно не подтверждает другое. Для каждого обязательного критерия нужны наблюдение и ответственный за приемку; blocked, failed и not-run остаются видимыми.

Минимальная трассировка: требование → сценарий приемки → проверяемый объект → свидетельство. Незаполненные пункты плана и самооценка агента не подтверждают поведение. Новая версия требует проверки затронутых критериев; не переноси успешный статус старого артефакта автоматически.

## Как проверить

- Все критерии конкретного релиза подтверждены → принять → отчет называет artifact, среду и владельца приемки.
- Проверен только формат документа → оценить готовность → содержание/публикация не получают автоматический passed.
- После успешного прогона изменился код → оценить статус → затронутая приемка отмечена непроверенной до нового свидетельства.

## Человек

Принимает результат по заранее заданным критериям и явно решает остаточный риск.

## Агент

Связывает каждый заявленный успех с объектом и проверкой; отдельно показывает незапущенные и заблокированные этапы.
