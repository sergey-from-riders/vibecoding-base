# Критерии готовности

## Коротко

Разделяйте готовый шаблон, работающий сервис и реально выполненные проверки.

## Плохо

```text
Production ready: папки и README созданы.
```

## Хорошо

```text
Шаблон готов. Runtime частичный.
Проверена структура. Нагрузочные тесты не выполнены.
```

## Почему

Наличие файлов не доказывает работоспособность.

## Когда применять

Это инженерное правило справочника, а не требование протокола. Первоисточник описывает подход или механизм; конкретный процесс выбирается проектом.

Для шаблонов, библиотек и релизов. Указывайте ограничения рядом с результатами.

## Как проверить

- Можно ли повторить заявленные проверки?

## Человек

Определяет наблюдаемые критерии приёмки и критические сценарии.

## Агент

Изучает существующий код, предлагает минимальное решение и связывает изменения с критериями приёмки.
