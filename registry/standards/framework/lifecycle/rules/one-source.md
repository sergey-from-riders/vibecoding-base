# Единый источник истины

## Коротко

Для нормативного содержания выбери один канонический источник и идентификатор его версии.

## Плохо

```text
Правило отдельно редактируется в Git, CMS и файле для агента.
Сайт обновился, экспорт остался старым; оба названы «актуальная версия».
```

## Хорошо

```text
Канон: Markdown на commit C, правило с устойчивым ID.
Снимок: все представления построены из C и прошли проверку.
Активная версия переключена с B на C одним согласованным действием.
Экспорт указывает C и исходный путь.
Исключение проекта: отдельная запись с областью и условием пересмотра.
```

## Почему

Происхождение и версия позволяют определить, какое требование применялось. Ссылка на изменяемую ветку без commit не воспроизводит прошлый результат.

## Когда применять

Для нормативных документов и производных представлений. Один небольшой Markdown-файл не требует специальной БД или генератора. Атомарный снимок нужен там, где согласованность нескольких представлений является контрактом потребителя.

### Подробные условия

Копии для сайта, поиска, экспорта или агента считаются производными и содержат ссылку на оригинал и ревизию. Изменяй первоисточник; не поддерживай вручную несколько равноправных текстов.

Локальные исключения проекта хранятся отдельно: ID правила, основание, область, владелец и срок/условие пересмотра. Они не переписывают общий стандарт. Если несколько представлений должны быть согласованы, строй полный снимок, проверяй его и переключай активную версию атомарно. При отказе оставляй предыдущую проверенную версию и показывай отставание; не объявляй частично обновленный набор единым снимком.

## Как проверить

- Изменен канон → собрать производные → каждый документ указывает один и тот же commit и исходный путь.
- Сборка нового снимка не прошла → открыть текущую публикацию → доступен целый предыдущий снимок, отставание известно.
- Проект имеет исключение → проверить применимые правила → канон сохранен, область и срок исключения доступны отдельно.

## Человек

Назначает канонический источник и принимает локальные исключения.

## Агент

Редактирует исходный документ, сохраняет provenance производных и не выдает локальное исключение за общую норму.
