# Распределение изменений

## Коротко

Для параллельного изменения различай владельца модуля, автора конкретной правки и ответственного за интеграцию.

## Плохо

```text
Два исполнителя независимо меняют формат счета.
«Файлы разные, значит конфликта нет; CODEOWNERS все защитит».
```

## Хорошо

```text
Владелец API: команда API; авторы: клиент и сервер.
Интегратор: назначенный участник, контракт revision 3.
Порядок: совместимый сервер → проверка старого клиента → новый клиент.
Worktree разделены; изменение контракта согласуется до реализации.
При несовместимости интеграция останавливается, локальные правки сохранены.
```

## Почему

Файловая изоляция предотвращает часть конфликтов записи, но совместимость определяется поведением поставщика и потребителя.

## Когда применять

Для нескольких участников или агентов. Если разделение не экономит время и создает зависимость, один исполнитель допустим. Отдельные роли могут выполнять один человек; дополнительная команда не требуется.

### Подробные условия

Укажи границы файлов и общего контракта. Пересечение по контракту требует согласованной версии, порядка внесения и проверки совместимости, даже если исполнители меняют разные файлы.

Отдельные worktree изолируют рабочие каталоги, но не устраняют смысловые конфликты. CODEOWNERS задает маршрутизацию ревью по настройке хостинга, а не блокировку одновременной записи. При неожиданном пересечении останови только конфликтующую часть, согласуй интеграцию и сохрани обе правки.

## Как проверить

- Независимые изменения → объединить → каждый результат проверен, область ответственности ясна.
- Две правки меняют одно поле контракта → провести интеграцию → несовместимость обнаружена до выпуска.
- Worktree различны, контракт общий → изменить версию → интегратор применяет согласованный порядок, а не считает изоляцию доказательством совместимости.

## Человек

Назначает владельца общего контракта и ответственного за объединение.

## Агент

Сообщает о затронутой общей границе, координирует порядок и не редактирует чужую активную область без согласованной передачи.
