# Доказательства выполнения

## Коротко

Отчёт агента должен отражать фактический ответ системы и выполненные проверки.

## Плохо

```text
Команда запущена → «Всё опубликовано».
```

## Хорошо

```text
Сборка завершена. URL проверен.
Отдельно указаны непроверенные сценарии.
```

## Почему

Запуск операции ещё не означает её успешное завершение.

## Когда применять

Это инженерное правило справочника, а не требование протокола. Первоисточник описывает подход или механизм; конкретный процесс выбирается проектом.

Для изменения файлов, публикации, платежей и доставки сообщений.

## Как проверить

- Есть ли подтверждение конечного состояния?

## Человек

Принимает результат по наблюдаемому поведению и заявленным ограничениям.

## Агент

Соблюдает выданные полномочия, проверяет результат инструментов и явно сообщает о недоступных проверках.

Контроль результата:

- Есть ли подтверждение конечного состояния?
