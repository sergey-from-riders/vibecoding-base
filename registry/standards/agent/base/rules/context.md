# Контекст проекта

## Коротко

Инструкции проекта должны объяснять активный стек, важные ограничения и команды проверок.

## Плохо

```text
Прочитай весь репозиторий и догадайся.
```

## Хорошо

```text
Прочитай AGENTS.md → контракт → нужный модуль.
Проверь: typecheck и тест сценария.
```

## Почему

Избыточный контекст затрудняет поиск важных требований.

## Когда применять

Это инженерное правило справочника, а не требование протокола. Первоисточник описывает подход или механизм; конкретный процесс выбирается проектом.

Путь к инструкциям зависит от агента. AGENTS.md — соглашение проекта, не общий протокол.

## Как проверить

- Новый участник может найти нужные файлы без угадывания?

## Человек

Определяет цель задачи и сообщает ограничения, которых нет в репозитории.

## Агент

Соблюдает выданные полномочия, проверяет результат инструментов и явно сообщает о недоступных проверках.

Контроль результата:

- Новый участник может найти нужные файлы без угадывания?
