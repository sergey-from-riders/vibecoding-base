# Vue: computed и производное состояние

## Коротко

Значение, полностью вычисляемое из реактивных данных, описывайте чистым computed. Не поддерживайте его вторую копию через watch, если нет отдельного побочного эффекта.

## Плохо

```javascript
const items = ref([{ quantity: 2 }]);
const total = ref(0);
watch(items, value => {
  total.value = value.reduce((sum, item) => sum + item.quantity, 0);
}); // Нет начального расчета; изменение вложенного quantity не отслежено.
```

## Хорошо

```javascript
import { computed, ref } from 'vue';

const items = ref([{ quantity: 2 }]);
const total = computed(() =>
  items.value.reduce((sum, item) => sum + item.quantity, 0)
);
// Меняем источник: items.value[0].quantity = 3.
// total.value обновится при следующем чтении; вручную его не присваиваем.
```

## Почему

Две копии одного состояния требуют синхронизации при каждом пути изменения. computed связывает результат с прочитанными реактивными зависимостями и кеширует вычисление до их изменения.

## Когда применять

Vue 3 Composition API, обычный глубокий `ref` массива и числовые quantity. В getter нет изменения массива, записи в другие refs, HTTP-запроса или изменения DOM. Возвращаемое производное значение рассматривайте как доступное для чтения.

`watch` нужен для побочного эффекта, например сохранения настройки или отменяемого запроса; он не запрещен. Плохой пример показывает неполную ручную синхронизацию, а не невозможность правильно настроить watch.

Нереактивное `Date.now()` или чтение обычного изменяемого объекта не создает зависимость. Для обновления времени нужен реактивный источник с управляемым жизненным циклом. При `shallowRef` внутренние изменения не ведут себя как у обычного ref: используйте согласованный способ замены/уведомления.

Пример считает количество единиц. Для денег отдельно соблюдайте точность и валюту; computed не исправляет floating-point арифметику.

## Как проверить

| Вход и действие | Ожидаемый результат | Свидетельство |
| --- | --- | --- |
| Начальный массив с quantity=2 | total сразу равен 2 при чтении | Проверка computed и интерфейса |
| Изменен quantity на 3; затем заменен массив | Значение соответствует обоим изменениям | Два отдельных сценария |
| Пустой массив и удаление последнего элемента | total=0, нет устаревшей копии | Проверка границы |
| Getter вызван повторно без изменения источника | Нет сети, записи или мутации; для времени не обещано обновление без реактивного источника | Наблюдение эффектов и тест зависимости |

Тест самого reduce подтверждает арифметику, но не реактивность Vue.

## Человек

Определяет единственный источник данных и отделяет вычисление от побочного эффекта.

## Агент

Проверяет начальное чтение, вложенную мутацию и замену массива, учитывает ref/shallowRef. Не использует computed для запуска async-операции.
