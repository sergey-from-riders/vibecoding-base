# Интеграционные тесты

## Коротко

Проверяй границу с реальной совместимой зависимостью, когда поведение зависит от ее протокола, транзакций, схемы или ограничений.

## Плохо

```text
Тест на SQLite назван проверкой PostgreSQL-миграции.
Один общий namespace; cleanup удаляет данные по переданному URL без защиты.
```

## Хорошо

```text
Контракт: PostgreSQL целевой major + нужные расширения/роли/collation.
Сценарии: новая БД; обновление предыдущей схемы с характерными данными.
Каждый запуск: свой namespace и credentials только к тестовой области.
Cleanup: проверка окружения и владельца ресурсов; production недоступен.
Отличия от рабочей среды указаны в отчете.
```

## Почему

Mock и другой движок не воспроизводят важные свойства настоящей зависимости; изоляция делает интеграционные проверки повторяемыми и ограничивает ущерб.

## Когда применять

Для изменений на границе БД, API, очереди и других сервисов. Sandbox поставщика допустим с перечисленными отличиями. Unit-тест остается полезным для чистой логики, но не выдается за проверку реального контракта.

### Подробные условия

Зафиксируй версию, расширения, collation/timezone, роли и настройки, которые влияют на проверяемый контракт. Отличия от production перечисляются; «используется SQL» не делает SQLite эквивалентом PostgreSQL.

Для изменений схемы проверь чистое развертывание и обновление поддерживаемого предыдущего состояния с характерными данными. Параллельные прогоны используют изолированные ресурсы. Создание и cleanup ограничиваются тестовой областью с явной проверкой цели; удобство очистки не оправдывает доступ к production.

## Как проверить

- Новая схема → развернуть на целевой зависимости → ограничения и права работают.
- Поддерживаемая старая схема с данными → обновить → данные/контракт сохранены; не только empty DB.
- Параллельный запуск и ошибочный production URL → выполнить cleanup → чужие ресурсы/production недоступны для удаления.

## Человек

Выбирает существенные параметры эквивалентности и разрешенную тестовую область.

## Агент

Проверяет engine/config и upgrade-путь; выводит ограничения sandbox и ограничивает cleanup ресурсами своего запуска.
