# Регрессионные тесты

## Коротко

Для исправляемого дефекта сохрани проверку наблюдаемого нарушения и ожидаемого контракта.

## Плохо

```text
Новый тест проходит после фикса; старая версия не проверена.
Либо старая версия падает на установке, и это названо воспроизведением бага.
```

## Хорошо

```text
Дефект: чужой счет доступен по ID.
Проверка: пользователь A запрашивает счет B, ожидается отказ без данных.
Старая версия: assertion обнаруживает раскрытие на тестовых данных.
Новая версия: тот же сценарий проходит; причина отказа окружения исключена.
Связь: дефект → инвариант → regression test.
```

## Почему

Регрессия доказывает, что проверка различает ошибочное и ожидаемое поведение, а не просто согласуется с текущим кодом.

## Когда применять

Для исправления поведения с риском повторения. Механической правке текста может хватить проверки diff/ссылок. Если старая среда недоступна, это явно ограничивает доказательство; нельзя безопасностью оправдать ложное «воспроизведено».

### Подробные условия

Покажи, что она выявляет дефект на прежней реализации и проходит на исправленной. Тест может быть написан после исправления: важна проверка обеих версий, а не время создания файла.

Падение старой версии должно происходить по нужному assertion, а не из-за сломанной установки или недоступной сети. Если автоматизация несоразмерна, сохрани воспроизводимую ручную приемку и ее ограничение. Опасный дефект воспроизводится на изолированных синтетических данных, без реальных платежей, утечки или повреждения production.

## Как проверить

- Тест написан после фикса → выполнить на old/new в изоляции → правильный assertion падает только на old.
- Old не установился → оценить → blocked, а не подтвержденная регрессия.
- Дефект затрагивает деньги/данные → воспроизвести синтетически → реального внешнего эффекта нет; ограничение модели указано.

## Человек

Подтверждает ожидаемый бизнес-инвариант и безопасную среду воспроизведения.

## Агент

Проверяет причину падения old и успех new; не изменяет assertion только ради зеленого результата.
