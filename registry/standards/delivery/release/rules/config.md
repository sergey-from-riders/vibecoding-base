# Конфигурация окружения

## Коротко

Описывай используемые параметры конфигурации: тип, допустимый диапазон, обязательность, безопасное значение по умолчанию и взаимные ограничения.

## Плохо

```text
Платежи включаются, если случайно найден ключ.
Нет production-ключа → использовать test-ключ.
Reload меняет URL, затем падает до смены credentials.
```

## Хорошо

```text
payments.enabled = false: платежный клиент не создается.
enabled = true: нужны подходящие друг другу environment, URL и credentials.
timeoutMs: целое в выбранном допустимом диапазоне.
Приоритет: default < файл < deployment override, записан в контракте.
Неверный кандидат reload отклонен целиком; прежний снимок остается активным.
```

## Почему

Ранний отказ и целостный снимок предотвращают работу с несовместимыми параметрами, а безопасная диагностика не раскрывает секреты.

## Когда применять

Для параметров, отличающихся между развертываниями. Переменные среды — один способ передачи; правило не требует хранить все только в env. Секреты и их ротация рассматриваются в security.secrets.

### Подробные условия

Явно задай приоритет источников. Неизвестные ключи в управляемой приложением конфигурации выявляются как ошибка/предупреждение по принятой политике; посторонние системные переменные окружения не нужно запрещать.

Проверяй конфигурацию до readiness и открытия рабочего трафика. Ошибка называет параметр и условие, но не значение секрета. Необязательная функция отключается явно и не требует своего секрета в отключенном состоянии. Для reload проверь целый кандидат и переключи согласованный снимок; при ошибке сохрани предыдущий. Параметры, требующие перезапуска, не меняй частично.

## Как проверить

- Отсутствует обязательный ключ включенной функции → запустить → readiness не достигнута, ошибка не содержит секрет.
- Неверный тип/диапазон либо test-ключ с production-средой → загрузить → кандидат отклонен до внешнего вызова.
- Функция выключена без ключа; затем пришел невалидный reload → обработать → функция остается выключенной, предыдущая конфигурация цела.

## Человек

Определяет безопасные defaults, приоритет и параметры, для которых допустим reload.

## Агент

Проверяет полную конфигурацию и не подставляет тестовые credentials для устранения ошибки production-запуска.
