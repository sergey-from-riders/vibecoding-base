# Backup и restore

## Коротко

Резервная копия полезна, если из неё можно восстановить нужные данные за допустимое время.

## Плохо

```text
Файл backup существует — значит всё защищено.
```

## Хорошо

```text
Копия восстановлена в отдельной среде.
Проверены данные и время восстановления.
```

## Почему

Повреждение или отсутствие ключа шифрования обнаруживаются только при восстановлении.

## Когда применять

Выберите допустимую потерю данных и время простоя. Для PITR нужны рабочая цепочка WAL и проверенная процедура.

## Как проверить

- Когда последний раз успешно восстанавливали копию?

## Человек

Задаёт RPO/RTO и принимает результат учебного восстановления.

## Агент

Готовит воспроизводимые команды, проверяет состояние сервисов и прикладывает фактический результат.

Контроль результата:

- Когда последний раз успешно восстанавливали копию?
