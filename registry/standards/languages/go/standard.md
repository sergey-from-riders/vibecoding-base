# Go: язык и инструменты

Именование и экспорт, imports, типы и воспроизводимый выбор toolchain для нового Go-кода. Полный текст норм хранится в `rules/`; этот паспорт содержит область применения и навигацию.

## Применимость

Для нового кода и изменяемых участков существующего проекта. Опубликованные интерфейсы, внешние wire names и сгенерированные файлы имеют отдельный контракт: механическое переименование без проверки совместимости не требуется. Точная поддерживаемая версия языка, форматтер, type checker и матрица CI определяются проектом.

Серверные нормы — [backend/go](../../backend/go/standard.md); общие риски зависимостей — [безопасность](../../security/no-secrets/standard.md). Для PostgreSQL применяется [профиль данных](../../database/postgres/standard.md). При выборе правил фиксируйте commit корпуса и явные ID, а не несуществующий автоматический механизм подключения.
