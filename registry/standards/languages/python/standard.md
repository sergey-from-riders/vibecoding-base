## Применимость

Для нового кода и изменяемых участков существующего проекта. Опубликованные интерфейсы, внешние wire names и сгенерированные файлы имеют отдельный контракт: механическое переименование без проверки совместимости не требуется. Точная поддерживаемая версия языка, форматтер, type checker и матрица CI определяются проектом.

Серверные нормы — [backend/python](../../backend/python/standard.md); общие риски зависимостей — [безопасность](../../security/no-secrets/standard.md). Для PostgreSQL применяется [профиль данных](../../database/postgres/standard.md). При выборе правил фиксируйте commit корпуса и явные ID, а не несуществующий автоматический механизм подключения.
