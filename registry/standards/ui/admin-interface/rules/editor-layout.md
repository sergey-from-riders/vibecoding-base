# Вкладки и свойства

## Коротко

Поля можно группировать по вкладкам и перемещать между ними. Компоновка редактора сохраняет идентичность полей, права, введенные значения и доступ к ошибкам.

## Плохо

```text
Перенос поля между вкладками сбрасывает ввод. Удаленная вкладка делает ошибку обязательного поля недоступной.
```

## Хорошо

```text
field_id=delivery_address не зависит от вкладки.
После изменения layout значение и ошибка остаются привязаны к field_id.
Недоступное поле исключено сервером; неизвестная вкладка заменена допустимой секцией.
```

## Почему

Структура данных и структура представления изменяются независимо. Персональная компоновка не должна влиять на корректность записи.

## Когда применять

Для редакторов с вкладками, секциями и пользовательским порядком полей. Настройка layout не обязательна для простой формы.

### Требования

- В настраиваемом редакторе поддержите перетаскивание полей за явную ручку и перемещение через меню «Во вкладку…» без drag. Показывайте место вставки, сохраняйте изменения компоновки и позволяйте сбросить ее. Упорядочивание не требует вручную вводить числовую позицию.
- Свяжите данные, dirty-state и ошибки со стабильным field_id/путем, а не индексом вкладки или DOM-позицией.
- Версионируйте layout; задайте приоритет личной и общей конфигурации. Неизвестные поля удаляются, допустимые поля из удаленной вкладки перемещаются в известную секцию.
- Сервер контролирует доступ на чтение и запись; скрытый элемент не является защитой. Обновление прав не уничтожает молча несохраненный допустимый ввод.
- После переноса сохраните фокус по field_id; переход к ошибке открывает нужную секцию. Если поле исчезло, фокус получает доступный заголовок/следующее поле.

## Как проверить

- Измените схему и общую компоновку при заполненной форме: данные и ошибки сохраняются по идентификаторам.
- Проверьте удаленную вкладку, неизвестное поле, снижение прав и клавиатурный переход к ошибке.

## Человек

Задаёт исходные группы и доступ к общей настройке.

## Агент

Хранит компоновку отдельно от данных и обеспечивает перенос без мыши.
