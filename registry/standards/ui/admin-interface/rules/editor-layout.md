# Вкладки и свойства

## Коротко

Пользователь может группировать поля и перемещать их между вкладками.

## Плохо

```text
120 полей в одной форме.
Перенос поля меняет его имя в данных.
```

## Хорошо

```text
Вкладки: Основное, Цены, Медиа.
Поля перетаскиваются или переносятся через меню.
Идентификатор поля не меняется.
```

## Почему

Компоновка рабочего места и модель записи решают разные задачи. Перестановка не должна повреждать API-контракт или создавать правку содержимого.

## Когда применять

Большие редакторы. Персональные настройки отделены от общих; общая настройка требует права. Поиск и «Все свойства» позволяют найти скрытое вкладкой поле.

## Как проверить

- Перенесите поле и проверьте сохранённое значение.
- Сбросьте компоновку без изменения черновика.

## Человек

Задаёт исходные группы и доступ к общей настройке.

## Агент

Хранит компоновку отдельно от данных и обеспечивает перенос без мыши.

## Пример применения

Поле price остаётся тем же полем после переноса из «Основного» в «Цены». Счётчики изменений остаются у фактических полей, а не у старых позиций.
