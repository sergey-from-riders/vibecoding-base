# Галерея и описание медиа

## Коротко

Галерея разделяет ресурс и его использование, задает обложку и хранит контекстные метаданные.

## Плохо

```text
Один alt используется во всех языках. Удаление обложки молча назначает другое изображение, а конкурентная подпись теряется.
```

## Хорошо

```text
asset_id=12; usage_id=product_8_photo_2; locale=ru.
Alt и подпись принадлежат usage; технические размеры — asset.
Удаление cover требует выбора новой обложки или явного состояния «без обложки».
```

## Почему

Смысл изображения зависит от страницы и языка. Идентификатор файла не определяет доступное описание.

## Когда применять

Для повторно используемых изображений и галерей. Декоративное изображение имеет пустой alt, если оно действительно не несет содержания.

### Требования

- Разделите asset_id и usage_id. Технические свойства принадлежат ресурсу; alt/подпись/локализация — контексту использования, с явными правилами наследования.
- Обложка задается стабильным usage_id. Для удаления, недоступности и пустой галереи определите явное поведение без случайной замены.
- Порядок, подписи, alt и обложка сохраняются с base revision; конфликт не перезаписывает изменения другого редактора.
- Описание должно соответствовать функции изображения; ссылка-изображение имеет доступное имя. Важные данные не передаются только картинкой.

## Как проверить

- Используйте один asset в двух контекстах и языках, измените один alt: другой контекст не меняется.
- Удалите обложку, отзовите доступ и одновременно измените подписи; проверьте состояния и конфликт.

## Человек

Выбирает обложку и пишет подходящие описания.

## Агент

Перемещает объект целиком и не связывает подписи с индексом массива.
