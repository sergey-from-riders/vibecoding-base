# Групповые действия

## Коротко

Действия над выбранными записями показываются в плавающей нижней панели с количеством записей. Групповая операция имеет фиксированную область, модель частичного успеха и проверяемый итог.

## Плохо

```text
Кнопка удаления получает текущий фильтр. После timeout UI повторяет запрос и показывает «Удалено все».
```

## Хорошо

```text
Нижняя панель: «Выбрано 79 · Изменить статус · Удалить · Снять выбор».
operation_id=op_42; selection_revision=8; count=79.
Модель partial: 76 success, 2 forbidden, 1 conflict.
Timeout: outcome=unknown; клиент запрашивает op_42, не создает новую операцию.
```

## Почему

Расположение панели не определяет надежность групповой операции. Панель может быть верхней, нижней или встроенной, если область и состояние доступны.

## Когда применять

Для операций над несколькими объектами. Подтверждение нужно для действия, которое требует его по риску или полномочиям; ранее выданное точное разрешение учитывается.

### Требования

- Панель появляется при непустом выборе и остается доступной при прокрутке. Зарезервируйте место под нее, учитывайте safe area и экранную клавиатуру; последняя строка и фокус не перекрываются. Длинные подписи переносятся, все действия доступны клавиатурой.
- Свяжите операцию с revision выбранного набора, действием, параметрами и субъектом. До запуска явно покажите масштаб и последствия.
- Определите atomic либо partial semantics. Для partial выдавайте итог по каждому ID и возможность безопасно повторить только неуспешные элементы.
- Используйте стабильный operation_id/идемпотентный повтор; неизвестный исход отличается от отказа. Статус задачи доступен после перезагрузки.
- Для долгой задачи задайте точки повторной авторизации, отмену до/между эффектами и состояние уже выполненных действий. Отмена не обещает откат без такой реализации.

## Как проверить

- Смоделируйте частичный отказ, истечение прав, timeout после эффекта, повтор и отмену: счетчики сходятся с фактическим результатом.
- Измените выбор после подтверждения: сервер не применяет старое разрешение к новому набору.

## Человек

Выбирает массовые действия и условия подтверждения.

## Агент

Показывает фактические результаты и не скрывает отказы доступа.
