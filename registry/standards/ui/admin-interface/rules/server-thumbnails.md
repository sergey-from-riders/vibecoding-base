# Серверные превью

## Коротко

Для списка отдавайте ограниченные производные изображения, соответствующие CSS-размеру, плотности экрана и правам доступа.

## Плохо

```text
Ячейка 50 CSS px получает оригинал 12 MB. Приватное изображение кешируется по общедоступному URL без версии.
```

## Хорошо

```text
Ячейка 50×50 CSS px; варианты 50/100/150 px для DPR 1/2/3.
Ключ: asset_version + transform + output_format.
Бюджет размера задан профилем; приватный вариант проверяет доступ.
```

## Почему

Размер отображения и размер ресурса различаются. Число 50 является примером компоновки, а не универсальным стандартом.

## Когда применять

Для списков с изображениями. Генерация может выполняться заранее или сервисом преобразования; выбор технологии не меняет контракт результата.

### Требования

- В таблице показывайте одно превью и на нем «+N» — количество остальных доступных пользователю изображений, а не общее число вместе с обложкой. Для 12 изображений это «+11». Счетчик имеет доступную подпись; галерея или оригинал открываются по явному действию без перехвата перехода по строке.
- Определите CSS-размер, поддерживаемый DPR, форматы и бюджет байтов для типичных изображений. Выберите srcset/sizes или эквивалентный явный подбор.
- Сохраняйте пропорции по выбранному contain/crop; учитывайте ориентацию и прозрачность. Поврежденный или неподдерживаемый файл дает контролируемый placeholder.
- Ключ производной включает версию оригинала и параметры преобразования. Замена оригинала создает новый ключ; старые варианты удаляются по политике ссылок/хранения.
- Приватные производные защищаются наравне с оригиналом; публичный кеш не получает приватные ответы. Оригинал не загружается автоматически при показе списка.

## Как проверить

- В Network проверьте реальный ресурс, байты и размеры при DPR 1/2/3; CSS-уменьшение оригинала не проходит приемку.
- Замените оригинал, отзовите доступ, загрузите поврежденный файл; проверьте новую версию, отказ доступа и placeholder.

## Человек

Определяет размер и область использования превью.

## Агент

Создаёт производные файлы на сервере, кеширует их по версии оригинала.
