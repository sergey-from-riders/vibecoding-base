# Добавление медиа

## Коротко

Импорт медиа ограничивает ресурсы, проверяет файл и управляет временными загрузками до привязки к записи.

## Плохо

```text
URL скачивается сервером без ограничений; отмененная загрузка навсегда остается публичным файлом.
```

## Хорошо

```text
Файл: count<=профиль, bytes<=лимит; upload_id связан с пользователем и сроком.
Карантин → проверка типа/декодирования → готовность → привязка.
Отмена закрывает upload_id; временные объекты удаляются по TTL.
```

## Почему

Выбор файла, вставка и drag являются способами ввода. Безопасность загрузки и жизненный цикл определяются независимо от интерфейса.

## Когда применять

Для редактора медиа этого профиля предусмотрены выбор нескольких файлов, drop, вставка из буфера и импорт по прямой ссылке. Способ, недоступный в конкретном браузере или запрещенный политикой проекта, явно обозначается; доступный file picker сохраняется.

### Требования

- Показывайте прогресс, отмену и повтор отдельно для каждого файла. Вставка в текстовое описание остается редактированием текста; перехватывайте paste только в предназначенной для медиа области. Не считывайте буфер фоново без действия пользователя.
- Задайте число файлов, размер одного/набора, разрешенные форматы, лимит декодированных пикселей/распаковки, время и параллелизм. Расширение и MIME клиента не считаются доказательством типа.
- До проверки храните объект в закрытом временном состоянии. Привязка к записи проверяет владельца, права и готовность; прогресс передачи не означает готовность файла.
- Повтор с тем же upload_id не создает новый логический ресурс. Отмена, обрыв, ошибка и истечение запускают очистку временных объектов с учетом активных ссылок.
- Серверный импорт URL выполняет требования integrations.files и security.ssrf, включая проверку перенаправлений и адресов. Не открывайте произвольные внутренние URL.

## Как проверить

- Проверьте превышение количества/размера, поврежденный файл, отмену, обрыв, повтор и TTL очистки.
- Для URL проверьте redirect во внутреннюю сеть; для интерфейса — клавиатурный file picker без drag/paste.

## Человек

Определяет разрешённые форматы, ограничения и права загрузки.

## Агент

Показывает отдельные состояния файлов и повторяет только неуспешные.
