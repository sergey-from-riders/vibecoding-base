# Навигация по строке

## Коротко

Запись открывается реальной ссылкой и кликом по свободной области строки. Обработчик строки не перехватывает вложенные действия, ссылки и выделение текста.

## Плохо

```text
Обработчик строки открывает карточку при выделении текста, клике checkbox и завершении перетаскивания.
```

## Хорошо

```text
Название записи — <a href="/records/42">.
Checkbox, button, input, select, textarea, contenteditable и ссылки выполняют собственное действие.
Возврат восстанавливает фокус на записи либо на ближайшем доступном элементе списка.
```

## Почему

Ссылка сохраняет стандартное открытие в новой вкладке и доступность. Клик по свободной области строки допустим как дополнительное действие.

## Когда применять

Для таблиц и списков с карточкой записи. Двойной клик не должен быть единственным способом открытия.

### Требования

- Не имитируйте ссылку одним onClick на tr. Для основной навигации сохраняйте href, Enter, модификаторы и среднюю кнопку; не отменяйте их без отдельной причины.
- Обработчик свободной области исключает интерактивных потомков, contenteditable, выделение текста и завершение drag. Один жест выполняет одно действие.
- Определите поведение одиночного/двойного клика; двойной клик не должен создавать две навигации или две мутации.
- При возврате восстановите запрос, позицию и фокус по стабильному ID. Если запись исчезла, выберите соседнюю доступную строку или заголовок списка и сообщите об изменении.

## Как проверить

- Проверьте левую/среднюю кнопку, Ctrl/Cmd-click, Enter, двойной клик, выделение текста, checkbox, contenteditable и drag.
- Вернитесь после удаления записи и после смены фильтра; фокус должен иметь определенную доступную цель.

## Человек

Разделяет переход к записи и действия внутри строки.

## Агент

Проверяет всплытие событий и сохраняет семантику ссылок и кнопок.
