# Навигация по строке

## Коротко

Открывайте запись по свободной области строки, сохраняя самостоятельную работу вложенных элементов.

## Плохо

```text
Нажатие «Удалить», чекбокса или ссылки региона
также открывает карточку тура.
```

## Хорошо

```text
Свободная область → карточка тура.
Чекбокс → выбор; регион → список региона.
Выделение текста и перетаскивание не открывают запись.
```

## Почему

Всплытие события не должно запускать два разных действия. Настоящая ссылка в названии сохраняет стандартное поведение браузера.

## Когда применять

Таблицы с переходом к записи. Исключайте интерактивные элементы, contenteditable, перетаскивание и выделение текста. Ctrl/Cmd-клик по ссылке продолжает открывать новую вкладку; Shift-выбор строки не превращается в навигацию.

## Как проверить

- Нажмите каждый вложенный элемент и выделите текст.
- Откройте название клавиатурой и в новой вкладке.

## Человек

Разделяет переход к записи и действия внутри строки.

## Агент

Проверяет всплытие событий и сохраняет семантику ссылок и кнопок.

## Пример применения

В туре ссылка «Камчатка» ведёт к связанному списку; свободная часть строки открывает тур. Не превращайте всю таблицу в набор вложенных ссылок.
