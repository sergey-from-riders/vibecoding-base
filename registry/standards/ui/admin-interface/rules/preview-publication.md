# Предпросмотр и публикация

## Коротко

Проверяйте черновик в предпросмотре и публикуйте отдельной кнопкой.

## Плохо

```text
Кнопка «Просмотр» открывает старую страницу.
Автосохранение сразу меняет сайт.
При начале задачи показано «Опубликовано».
```

## Хорошо

```text
Предпросмотр показывает текущий черновик.
«Опубликовать» применяет проверенную версию.
«Публикуется» сменяется подтверждённым результатом.
```

## Почему

Сохранение, принятие публикации и появление на сайте — разные состояния. Подмена одного другим создаёт ложное подтверждение.

## Когда применять

Контентные системы с публикацией. Сервер проверяет права, версию и обязательные поля; предпросмотр приватного черновика не должен становиться публичной ссылкой без контроля доступа.

## Как проверить

- Сопоставьте черновик, предпросмотр и публичную страницу.
- Проверьте задержку фоновой публикации и её ошибку.

## Человек

Проверяет содержимое и явно публикует его в рамках полномочий.

## Агент

Показывает подтверждённые состояния и не публикует от изменения тумблера.

## Пример применения

После кнопки можно показать «Сохранено, обновление сайта выполняется». Финальное сообщение «Изменения доступны» требует проверки применённой версии.
