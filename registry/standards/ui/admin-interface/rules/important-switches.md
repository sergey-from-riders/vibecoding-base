# Тумблеры важных свойств

## Коротко

Переключатель явно показывает состояние, момент применения и последствия изменения конкретного свойства.

## Плохо

```text
При загрузке неизвестное значение отображается false. Тумблер «Публикация» выглядит мгновенным, но сохраняется только после общей кнопки.
```

## Хорошо

```text
Статус: «Включено в черновике; вступит в силу после публикации».
Загрузка: значение неизвестно, изменение недоступно.
Немедленная настройка после отказа возвращает подтвержденное состояние с сообщением.
```

## Почему

Вид контрола должен соответствовать семантике действия. Для отложенного изменения checkbox или select могут быть понятнее переключателя.

## Когда применять

Для двоичных свойств с определенными состояниями. Не используйте двоичный переключатель для unknown, mixed или многошагового процесса без отдельного отображения.

### Требования

- Для каждого поля документируйте default, текущий источник истины, момент применения и последствия. Default не подменяет неизвестное серверное значение.
- Различайте loading, editable, readonly, forbidden, pending и failed. Не разрешайте действие, пока состояние и право не установлены.
- Немедленное изменение получает подтверждение сервера и определенное поведение при отказе/неизвестном исходе. Отложенное остается частью draft и явно подписано.
- Контрол имеет доступное имя и состояние; важное последствие показано рядом, а не только в hover-подсказке.

## Как проверить

- Проверьте загрузку, отказ, отзыв прав, изменение другим пользователем и повтор после timeout.
- Проверьте клавиатуру/скринридер и понимание момента применения без знания внутреннего workflow.

## Человек

Выделяет свойства с существенными последствиями.

## Агент

Отделяет значение черновика от подтверждённого состояния сайта.
