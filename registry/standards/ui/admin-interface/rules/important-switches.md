# Тумблеры важных свойств

## Коротко

Важные логические свойства имеют заметные тумблеры с понятной подписью.

## Плохо

```text
Неподписанный чекбокс среди 40 полей.
Новая запись уже отмечена «Опубликована».
```

## Хорошо

```text
Активен: включено. Показывать на главной: выключено.
Изменения в черновике.
Отдельная кнопка «Опубликовать».
```

## Почему

Визуальный акцент помогает заметить свойство с большим влиянием. Однако форма элемента сама по себе не должна запускать публикацию.

## Когда применять

Ключевые логические свойства записи. Обычные параметры могут оставаться чекбоксами. Подпись объясняет состояние; не используйте один цвет и не называйте неподтверждённый черновик опубликованным.

## Как проверить

- Переключите свойство: публичная запись не меняется до публикации.
- Проверьте подпись, клавиатуру и состояние новой записи.

## Человек

Выделяет свойства с существенными последствиями.

## Агент

Отделяет значение черновика от подтверждённого состояния сайта.

## Пример применения

Тумблер «Показывать на главной» изменяет поле черновика. После публикации отдельно проверяется появление записи на главной странице.
