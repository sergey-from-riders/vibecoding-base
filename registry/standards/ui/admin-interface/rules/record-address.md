# Адрес записи

## Коротко

Изменение опубликованного адреса сохраняет работоспособность прежних ссылок.

## Плохо

```text
Переименовали статью — старый адрес стал 404.
Новый адрес занят другой статьёй.
```

## Хорошо

```text
Редактор показывает полный будущий адрес и конфликт.
Прежний опубликованный адрес перенаправляет на текущий.
Удаление старого адреса — отдельное действие.
```

## Почему

Опубликованный адрес может быть в закладках и внешних ссылках. Проверка уникальности нужна на сервере, а история помогает понять последствия изменения.

## Когда применять

Записи с публичными адресами. Не создавайте цепочки и циклы перенаправлений. Если материал удалён намеренно, политика удаления может требовать 404 или 410 вместо перенаправления.

## Как проверить

- Откройте прежний адрес после двух переименований.
- Попробуйте занятый адрес и проверьте сообщение о конфликте.

## Человек

Определяет адрес и решение об удалении старых ссылок.

## Агент

Проверяет уникальность и историю, сохраняет прямой переход к текущему адресу.

## Пример применения

При смене /tours/old.html на /tours/new.html старая ссылка ведёт к тому же туру. Автогенерация адреса из названия не переписывает вручную выбранный адрес без согласованного правила.
