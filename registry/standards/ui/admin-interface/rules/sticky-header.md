# Закреплённый заголовок

## Коротко

При прокрутке пользователь продолжает видеть названия столбцов.

## Плохо

```text
Через 20 строк непонятно, где цена и где остаток.
Закреплённая шапка закрывает первую строку.
```

## Хорошо

```text
Шапка остаётся у верхней границы области таблицы.
При горизонтальной прокрутке заголовки движутся со столбцами.
```

## Почему

Контекст столбца нужен при сравнении длинных списков. Несколько независимо прокручиваемых областей усложняют управление.

## Когда применять

Длинные таблицы. Учитывайте высоту общей навигации, фон и порядок наложения. Закрепление должно работать при изменении ширины столбцов и масштаба страницы.

## Как проверить

- Прокрутите в обе стороны и увеличьте масштаб.
- Первая и последняя строки не перекрыты.

## Человек

Определяет основную область прокрутки.

## Агент

Проверяет совпадение ширин и отступ от общей шапки.

## Пример применения

Один scroll-контейнер содержит и таблицу, и sticky-заголовок. При открытой нижней панели остаётся отступ под последней строкой.
