# Закрепленный заголовок

## Коротко

Закрепление заголовка сохраняет контекст столбцов и не закрывает фокус или содержимое.

## Плохо

```text
Две sticky-панели перекрывают активную кнопку. Клонированный header озвучивается скринридером второй раз.
```

## Хорошо

```text
Отступ таблицы учитывает высоту всех фиксированных панелей.
Фокусируемая строка прокручивается в видимую область.
Семантический заголовок единственный; визуальная копия не содержит доступных дублей.
```

## Почему

Sticky является вариантом компоновки. Его применимость зависит от высоты области, масштаба и поведения фокуса.

## Когда применять

Для длинных таблиц с прокруткой. На небольшом экране закрепление можно отключать, если оно лишает пользователя рабочей области.

### Требования

- Предпочитайте закрепление существующих th. Если нужна визуальная копия, исключите ее из дерева доступности и tab-порядка, сохранив реальные связи заголовков.
- Рассчитывайте суммарный отступ нескольких закрепленных панелей; переход к ошибке или строке не оставляет фокус за ними.
- Ограничьте высоту закрепленной области и предусмотрите отключение при узком экране/большом масштабе.

## Как проверить

- Пройдите таблицу клавиатурой при 100%, 200% и ширине 320 CSS px; активный элемент и его индикатор не перекрыты.
- Проверьте скринридером отсутствие дублированных заголовков и соответствие горизонтальной прокрутки.

## Человек

Определяет основную область прокрутки.

## Агент

Проверяет совпадение ширин и отступ от общей шапки.
