# Контекстная справка

## Коротко

Сложное поле объясняется рядом с местом работы: назначение, формат и результат.

## Плохо

```text
Поле называется property_43.
Справка описывает кнопку, которой больше нет.
```

## Хорошо

```text
«Цена за участника, ₽».
Подсказка: что вводить, пример и где это появится.
Ограничения соответствуют действующей форме.
```

## Почему

Пользователю важно влияние поля на результат. Внутренние пути и названия полезны разработчику, но не заменяют рабочее объяснение.

## Когда применять

Неочевидные свойства, связи, медиа и публикация. Простым полям не нужна длинная инструкция. Справку обновляют вместе с поведением; скрытие группы не должно описываться как удаление данных.

## Как проверить

- Пройдите шаги подсказки в действующей форме.
- Проверьте пример, ограничения и результат на сайте.

## Человек

Объясняет предметный смысл и типовые ошибки.

## Агент

Связывает справку с полями, проверяет примеры и не придумывает возможности.

## Пример применения

Возле галереи объясняется разница между удалением фото из поля и удалением файла, а возле адреса — последствия изменения опубликованной ссылки.
