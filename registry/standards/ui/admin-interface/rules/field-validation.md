# Поиск свойств и валидация

## Коротко

Поиск полей помогает навигации, а валидация отдельно проверяет данные и возвращает ошибки к определенной версии формы.

## Плохо

```text
Ответ проверки старого значения перезаписывает новую ошибку. Ошибка «Поле 3» относится к другому элементу после перестановки списка.
```

## Хорошо

```text
Ошибка: field_id=address, item_id=addr_8, code=postal_code_invalid,
message="Укажите допустимый почтовый индекс", form_revision=24.
Ответ для revision=23 отброшен.
Неполный draft сохраняется; publish возвращает список блокирующих ошибок с переходами к полям.
```

## Почему

Навигационный поиск не заменяет серверную проверку. Стабильная адресация ошибки необходима при вложенных объектах и динамических списках.

## Когда применять

Для форм с несколькими полями, вкладками и серверной валидацией. Валидация зависит от операции: сохранение черновика и публикация имеют разные требования.

### Требования

- Задайте формат пути: стабильные field_id и item_id либо JSON Pointer с привязкой к неизменной ревизии формы. Индекс массива без ревизии недостаточен.
- Сервер проверяет инварианты и права; клиентская проверка ускоряет обратную связь. Ответ содержит код, путь, понятное сообщение и проверенную ревизию.
- Определите допустимый незавершенный draft и ошибки, блокирующие публикацию. Не сообщайте «сохранено», если сервер отклонил сохранение.
- Для async-проверки используйте revision/sequence и отмену устаревших результатов. Поиск свойств работает по доступным полям и не раскрывает скрытые по правам значения.
- Покажите сводку и ошибки рядом с полями; переход открывает вкладку и сохраняет доступное описание ошибки.

## Как проверить

- Отправьте два значения с обратным порядком ответов, переставьте элементы списка и удалите поле; ошибка остается привязана к актуальному объекту.
- Сохраните неполный черновик, затем опубликуйте: проверьте различие правил и доступность переходов к ошибкам.

## Человек

Определяет ограничения и понятные сообщения.

## Агент

Связывает ошибку с полем и вкладкой, сохраняет пользовательский ввод.
