# Подготовленные правки агента

## Коротко

Правки агента представлены как проверяемый черновик конкретной версии.

## Плохо

```text
Агент пишет «Готово» и сразу меняет сайт.
После одобрения он дописал текст, публикация использует новые правки.
```

## Хорошо

```text
Было / стало, автор: агент, список изменений.
Человек может исправить или исключить изменения.
Кнопка публикует именно проверенную версию.
```

## Почему

Пользователь должен понимать масштаб операции. Одобрение старой версии не распространяется на незаметно изменившееся содержимое.

## Когда применять

Интерфейсы подготовки правок AI-агентом. Полномочия задаёт человек; техническая проверка не заменяет редакторскую оценку. Публикация проверяет права и версию на сервере, повтор запроса не дублирует действие.

## Как проверить

- Измените черновик после проверки: старое подтверждение не действует.
- Проверьте повтор публикации и исключение группы изменений.

## Человек

Проверяет существенные изменения и публикует в пределах своих прав.

## Агент

Подготавливает черновик, указывает фактические проверки и ждёт явного действия публикации.

## Пример применения

Редактор снимает группу «Описание», оставляя «Цена». Подтверждение связывается с ревизией и составом оставшихся изменений, а не только с ID записи.
