# Подготовленные правки агента

## Коротко

Предложение агента связано с точным набором изменений и выполняется в пределах действующих полномочий.

## Плохо

```text
Разрешение «обновить текст» используется для удаления других записей. Измененный после одобрения draft публикуется под тем же approval.
```

## Хорошо

```text
Разрешение: actor, targets, base_revisions, delta_digest, allowed_action, scope, expiry.
Перед применением сервер сверяет параметры и зависимости.
Имеющееся точное полномочие позволяет выполнить действие без повторного запроса.
```

## Почему

Проверяемая связь разрешения и операции предотвращает расширение объема. Дополнительное подтверждение не требуется там, где пользователь уже выдал достаточное разрешение.

## Когда применять

Для редакторского workflow предложений и публикации. Правило не отменяет заранее предоставленные полномочия на конкретную операцию.

### Требования

- Зафиксируйте target set, базовые ревизии, содержимое delta, инициатора/одобрившего, допустимое действие, масштаб и срок. Условия пересмотра разрешения определяются изменением этих параметров.
- Перед выполнением проверьте текущие права и базовые версии. Изменившийся delta или состав нельзя применять под старым разрешением.
- Группы правок имеют зависимости: исключение обязательной группы блокирует зависимую, а не создает частично некорректную запись. Конфликт с параллельным редактором показывается до эффекта.
- Применение/публикация использует operation_id и проверяемый итог. Разделяйте подготовку, одобрение и применение только там, где этого требует выбранный workflow.

## Как проверить

- Измените target, delta и базовую версию после одобрения: старое разрешение не расширяется автоматически.
- Исключите зависимость, повторите операцию после timeout и проверьте сценарий с заранее выданными полномочиями.

## Человек

Проверяет существенные изменения и публикует в пределах своих прав.

## Агент

Подготавливает черновик, указывает фактические проверки и ждёт явного действия публикации.
