# Автосохранение черновика

## Коротко

Любое содержательное изменение автоматически сохраняется в черновик.

## Плохо

```text
Название изменено, но сохраняется только основное описание.
При уходе со страницы всё исчезает.
```

## Хорошо

```text
Название, поля, связи и порядок → черновик.
Сохраняется… → Сохранено.
Ошибка → Не сохранено · Повторить.
```

## Почему

Пользователь не должен угадывать, какие поля сохраняются. Подтверждение сохранения допустимо только после ответа хранилища.

## Когда применять

Редакторы содержимого. Открытие записи не создаёт пустую ревизию; ввод можно объединять после короткой паузы, сохраняя порядок запросов. Автосохранение не равно публикации и не требует версии на каждое нажатие клавиши.

## Как проверить

- Измените название, связь и порядок; откройте черновик повторно.
- Отключите сеть и проверьте сообщение о несохранённых данных.

## Человек

Определяет жизненный цикл и срок хранения черновиков.

## Агент

Сериализует сохранения, показывает ошибки и защищает ввод при уходе.

## Пример применения

При ошибке сохранения редактор сохраняет локальный ввод и предлагает повтор. Кнопка публикации не отправляет устаревший серверный черновик поверх свежих локальных правок.
