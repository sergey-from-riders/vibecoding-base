# Версии и отмена

## Коротко

Изменённое поле показывает автора, время, прежнее и новое значения до публикации.

## Плохо

```text
После отмены поле прежнее, но рядом всё ещё
«Изменил редактор» и кнопка «Отменить».
```

## Хорошо

```text
Изменённое поле → автор, время, было / стало, отмена.
Значение снова опубликованное → отметка правки исчезает.
История операции сохраняется.
```

## Почему

Отметка должна описывать текущую разницу, а журнал — последовательность действий. Возврат значения не означает уничтожение истории.

## Когда применять

Черновики и версии записей. Поддержите отмену поля и восстановление версии в черновик. Сравнивайте значения с учётом типа: 0, false, null и пустая строка не взаимозаменяемы. Не придумывайте отсутствующего автора.

## Как проверить

- Верните поле вручную к опубликованному значению.
- Отметка и автор возле поля исчезли, журнал сохранился.

## Человек

Определяет видимость и срок хранения истории.

## Агент

Сравнивает канонические значения, сохраняет авторство человека и агента.

## Пример применения

Отмена цены возвращает опубликованную цену в черновик, не публикуя остальные изменения. Восстановление старой версии требует той же проверки, что обычная правка.
