# Выделение строк

## Коротко

Выбор записей должен быть явным и поддерживать диапазон через Shift.

## Плохо

```text
Клик по строке иногда открывает, иногда выделяет.
«Выбрать всё» молча включает неизвестные записи.
```

## Хорошо

```text
Первый столбец — чекбоксы.
Shift + чекбокс выбирает диапазон в текущем порядке.
«Выбрано 50 загруженных»; отдельно «Все 2000 найденных».
```

## Почему

Разница между видимой частью и всей выборкой критична для массовых действий. Выбор хранится по ID, а не по номеру строки.

## Когда применять

Таблицы с групповыми действиями. Заголовок имеет промежуточное состояние при частичном выборе. При изменении фильтра сбрасывайте выбор с понятным сообщением; подгрузка не выбирает новые строки молча.

## Как проверить

- Проверьте Shift в обоих направлениях и после сортировки.
- Измените запрос и проверьте состав выбранных ID.

## Человек

Определяет допустимый масштаб массовых действий.

## Агент

Разделяет диапазон загруженных строк и явный выбор всей выборки.

## Пример применения

Якорь диапазона — последняя выбранная строка. При смене сортировки старый якорь сбрасывается. Выбор по всей выдаче фиксирует запрос и повторно проверяет права на сервере.
