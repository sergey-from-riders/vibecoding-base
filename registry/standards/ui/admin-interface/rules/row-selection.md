# Выделение строк

## Коротко

Выделение задает конкретный набор записей и не расширяет область действия незаметно для пользователя.

## Плохо

```text
«Выбрать все 80» сохраняет только текст запроса. До удаления появились 20 записей, и сервер удаляет 100.
```

## Хорошо

```text
Режим explicit: ids=[1,2,3].
Режим all: selection_token=snapshot_8, count=80, excluded_ids=[7].
После истечения token действие остановлено; новый состав требует нового подтверждения.
```

## Почему

Количество на экране не фиксирует состав. Для группового действия нужен серверный контракт выбранного набора.

## Когда применять

Для таблиц с множественным выбором. Выбор видимых строк и всей выдачи должен быть различим.

### Требования

- Первый столбец содержит чекбоксы строк и общий чекбокс с состоянием частичного выбора. У каждого контрола есть доступное имя; его нажатие не открывает запись. Помимо мыши поддержите клавиатуру, Shift-диапазон и явное снятие выбора.
- Разделите explicit IDs и all-results по неизменяемому снимку или материализованному серверному набору. Храните исключенные ID, scope запроса и срок действия.
- Для Shift-диапазона задайте anchor по ID и порядку; после смены фильтра/сортировки сбрасывайте anchor и объясняйте судьбу текущего выбора.
- Повторно проверяйте доступ и допустимость операции по каждой записи. Недоступные строки не учитываются как успешно обработанные.
- Перед действием показывайте применимый состав и количество. Истечение, изменение состава или масштаба требует пересчета и подтверждения нового набора.

## Как проверить

- Выберите все, исключите две строки, добавьте новую запись и измените права: действие должно затронуть только согласованный допустимый набор.
- Проверьте истечение token, смену сортировки и Shift-диапазон; скрытого расширения выбора нет.

## Человек

Определяет допустимый масштаб массовых действий.

## Агент

Разделяет диапазон загруженных строк и явный выбор всей выборки.
