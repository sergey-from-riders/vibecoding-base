# Настройка столбцов

## Коротко

Персональная настройка столбцов сохраняет доступность данных, ограничения прав и совместимость со схемой.

## Плохо

```text
Сохраненный вид по старым названиям восстанавливает удаленный столбец secret_cost; закрепленные колонки закрывают всю таблицу.
```

## Хорошо

```text
Вид schema=4 хранит стабильные field_id.
Удаленное поле пропущено с уведомлением; запрещенное сервером не загружено.
На узком экране закрепление снимается; размер можно изменить кнопками.
```

## Почему

Настройка представления не является механизмом доступа. Стабильные идентификаторы позволяют переносить пользовательскую компоновку между версиями схемы.

## Когда применять

Для таблиц с настраиваемым набором, порядком, шириной и закреплением столбцов. Это контракт проекта; W3C определяет доступность управления, а не формат сохраненного вида.

### Требования

- Храните field_id, версию схемы и область настройки: пользователь, команда, тип записи. Переименование подписи не меняет ID; миграция удаляет неизвестные ID и сохраняет допустимые.
- Сервер повторно проверяет права на поля; восстановленный вид не запрашивает и не показывает запрещенные значения.
- Определите минимальные и максимальные ширины по типам данных. Для resize предоставьте управление без drag и клавиатурой, а также сброс.
- Ограничьте суммарную ширину закрепления доступной областью; на узком экране снимайте закрепление в определенном порядке.

## Как проверить

- Сохраните вид, удалите/переименуйте поле и понизьте роль; проверьте отсутствие запрещенных данных в ответе API.
- Измените ширину клавиатурой и одним указателем без перетаскивания; проверьте 320 CSS px, масштаб и сброс.

## Человек

Задаёт исходный вид и обязательные столбцы.

## Агент

Сохраняет настройки по стабильным ID столбцов и добавляет сброс.
