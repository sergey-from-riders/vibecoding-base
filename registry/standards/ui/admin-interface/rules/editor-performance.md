# Быстрое открытие формы

## Коротко

Основные поля не должны ждать загрузки всех дополнительных редакторов.

## Плохо

```text
Форма ждёт галерею, карту, историю и редактор программы.
Быстрый API объявлен доказательством быстрого интерфейса.
```

## Хорошо

```text
Основные поля доступны первыми.
Независимые данные запрашиваются параллельно.
Тяжёлый редактор загружается при открытии вкладки.
```

## Почему

Скорость ответа API не включает загрузку JavaScript и подготовку элементов к работе. Измерять нужно реальный пользовательский переход.

## Когда применять

Формы с тяжёлыми вкладками. Не откладывайте проверку доступа и не выдавайте ещё не загруженное поле за пустое. Оптимизация не должна терять черновики и ломать прямые ссылки.

## Как проверить

- Измерьте холодное открытие и повторный переход в браузере.
- Первое изменение основного поля сохраняется до загрузки медиа-вкладки.

## Человек

Определяет, какие поля нужны первыми.

## Агент

Разделяет время документа, API и готовности формы, проверяет живой сценарий.

## Пример применения

В Vibe дополнительные редакторы загружаются динамически, а запись и черновик читаются параллельно. Конкретное время зависит от сети и устройства; универсальные «0 мс» не обещаются.
