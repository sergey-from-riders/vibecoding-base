# Быстрое открытие формы

## Коротко

Измеряйте время до пригодности основной формы к вводу в зафиксированном окружении и с заданным бюджетом.

## Плохо

```text
«Форма быстрая» подтверждается видео разработчика. Сначала загружаются все вкладки, неизвестные данные сохраняются как пустые.
```

## Хорошо

```text
Метрика: от команды открытия до доступного ввода в обязательные поля.
Профиль: устройство, сеть, объем записи, cold/warm cache; бюджет p95 задан проектом.
Дополнительная вкладка загружается отдельно; неизвестное значение не сериализуется как пустое.
```

## Почему

Производительность проверяется воспроизводимым измерением. Ленивое чтение уменьшает начальную работу, но не должно повреждать данные.

## Когда применять

Для сложных редакторов. Конкретное значение бюджета зависит от пользователей и среды; произвольное универсальное число не задается.

### Требования

- Определите start/end метрики, выборку измерений, p50/p95, устройство, браузер, сеть, кеш и объем данных. Бюджет утверждается до оптимизации.
- Параллельно выполняйте независимые запросы; зависимые запускайте после получения необходимых ключей/ревизии. Запись и draft читаются согласованно либо несогласованность обнаруживается.
- Загружайте вторичные вкладки и тяжелые компоненты по потребности с доступными состояниями loading/error. Основной ввод не блокируется несвязанным ресурсом.
- Отсутствующие из-за lazy loading поля остаются unknown и не затирают серверные данные. Оптимизация не меняет base revision и надежность автосохранения.

## Как проверить

- Повторите измерения на зафиксированном профиле и сравните p95 с бюджетом; сохраните трассу и конфигурацию.
- Задержите вторичную вкладку и зависимый запрос, начните ввод и сохраните: неизвестные поля не обнуляются.

Определяет, какие поля нужны первыми.

## Агент
