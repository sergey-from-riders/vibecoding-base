# Сохранённые представления

## Коротко

Возвращайте пользователя в тот список и на ту позицию, с которой он открыл запись.

## Плохо

```text
Открыть тур из 400-й строки → назад.
Поиск пустой, сортировка сброшена, список наверху.
```

## Хорошо

```text
Назад → тот же запрос, столбцы и сортировка.
Восстановлена позиция выбранного тура.
Рабочий вид можно сохранить под названием.
```

## Почему

Потеря контекста заставляет повторять работу. Поисковые параметры в адресе также позволяют передать коллеге воспроизводимый вид списка.

## Когда применять

Каталоги с длительной обработкой записей. Персональные виды отделены от общих. Если запись исчезла или доступ изменился, восстановите запрос и ближайшую доступную позицию без показа закрытых данных.

## Как проверить

- Проверьте переход назад и прямую ссылку на выдачу.
- Настройки одного пользователя не меняют вид другого.

## Человек

Определяет полезные командные виды.

## Агент

Сохраняет запрос в URL, настройки по пользователю, позицию по стабильному ID.

## Пример применения

Вид «Неактивные туры без цены» хранит запрос и набор столбцов. Обновление данных не должно насильно возвращать пользователя к первой строке.
