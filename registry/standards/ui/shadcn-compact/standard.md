# shadcn Compact UI Profile

> Собрано автоматически из rules/*.md. Редактируйте исходные правила, затем выполните `node tools/handbook.mjs generate`.

## Называйте действие по его результату

### Коротко

Подпись кнопки должна объяснять, что произойдёт после нажатия.

### Плохо

```text
Кнопка «ОК» отправляет заявку и списывает деньги.
```

### Хорошо

```text
Кнопки «Сохранить черновик» и «Оплатить 500 ₽».
```

### Почему

Неясная подпись увеличивает вероятность ошибочного действия.

### Когда применять

Особенно важно для оплаты, публикации и удаления.

### Как проверить

- Можно ли предсказать результат без пробного нажатия?

### Источники

- [Первоисточник](https://www.w3.org/TR/WCAG22/)

Уровень: Рекомендуется. Проверено: 2026-11-09.

## Сделайте основные действия доступными с клавиатуры

### Коротко

Используйте семантические элементы и видимый фокус.

### Плохо

```html
<div onclick="save()">Сохранить</div>
```

### Хорошо

```html
<button type="submit">Сохранить</button>
```

### Почему

Кликабельный блок без семантики недоступен многим пользователям и вспомогательным средствам.

### Когда применять

Библиотека компонентов полезна, но не обязательна. Качественный нативный HTML допустим.

### Как проверить

- Пройдите страницу Tab, Shift+Tab, Enter и Escape.

### Источники

- [Первоисточник](https://www.w3.org/TR/WCAG22/)

Уровень: Обязательно. Проверено: 2026-11-09.

## Не передавайте смысл только цветом

### Коротко

Подпись, значок и достаточный контраст должны сохранять смысл без различения цветов.

### Плохо

```text
Красный блок и зелёный блок без подписей.
```

### Хорошо

```text
✕ Плохо: ошибка скрыта.
✓ Хорошо: ошибка объяснена.
```

### Почему

Не все пользователи одинаково воспринимают цвет.

### Когда применять

Целевой уровень — WCAG 2.2 AA; для обычного текста минимальный контраст 4.5:1 с предусмотренными стандартом исключениями.

### Как проверить

- Понятны ли состояния в чёрно-белом виде и при увеличении?

### Источники

- [Первоисточник](https://www.w3.org/TR/WCAG22/)

Уровень: Обязательно. Проверено: 2026-11-09.

## Сохраняйте читаемость на маленьком экране

### Коротко

Макет должен перестраиваться, а длинный код прокручиваться внутри своего блока.

### Плохо

```text
Две колонки по 600px на телефоне.
```

### Хорошо

```text
На компьютере — рядом.
На телефоне — друг под другом.
Код прокручивается внутри примера.
```

### Почему

Горизонтальная прокрутка всей страницы затрудняет чтение и навигацию.

### Когда применять

Для сравнений и документации; широкая таблица может иметь собственную область прокрутки.

### Как проверить

- Проверьте ширины 320 и 390px, увеличение и длинные слова.

### Источники

- [Первоисточник](https://www.w3.org/TR/WCAG22/)

Уровень: Обязательно. Проверено: 2026-11-09.

## Связывайте ошибку с полем формы

### Коротко

Сохраняйте введённые данные и показывайте, что именно нужно исправить.

### Плохо

```text
После отправки форма очищена, сверху «Ошибка».
```

### Хорошо

```text
Под email: «Проверьте адрес».
Текст сохранён; ошибка связана с полем.
```

### Почему

Пользователь не должен повторять ввод из-за исправимой ошибки.

### Когда применять

Проверка браузера улучшает удобство, но сервер всё равно проверяет данные.

### Как проверить

- Скринридер объявляет ошибку и проблемное поле?

### Источники

- [Первоисточник](https://www.w3.org/TR/WCAG22/)

Уровень: Обязательно. Проверено: 2026-11-09.

## Повторяйте знакомые элементы последовательно

### Коротко

Одинаковые действия должны выглядеть и вести себя одинаково во всех разделах.

### Плохо

```text
Три разных поведения фильтра в трёх списках.
```

### Хорошо

```text
Общий фильтр, пустое состояние и пагинация.
```

### Почему

Последовательность снижает количество действий, которые нужно изучить.

### Когда применять

shadcn — один из вариантов. Плотность, интервалы и число цветов выбираются по задаче, без универсального лимита 8px.

### Как проверить

- Кнопка не меняет размер при загрузке? Цели нажатия удобны?

### Источники

- [Первоисточник](https://www.w3.org/TR/WCAG22/)

Уровень: Рекомендуется. Проверено: 2026-11-09.
