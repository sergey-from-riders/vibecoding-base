# Персональные данные: веб-системы РФ

Навигация по модулю `legal/russia-web`. Единственные исходные тексты требований находятся в `rules/`.

## Область применения

14 правил для операций обработки персональных данных с применимым правом РФ: основания, политика, отдельное согласие, доказательства, реклама, cookies, локализация, трансграничная передача, обработчики, уведомления, сроки, обращения, распространение и инциденты.

| Поле | Значение |
| --- | --- |
| Раздел | `legal-ru` |
| Правил | 14 |
| Содержательная проверка | 2026-11-13 |
| Статус редакции | Кандидат; факт публикации проверяется отдельно |

Тексты 152-ФЗ в проверенной редакции от 26.07.2026 и статьи 18 закона 38-ФЗ; письмо Минцифры отделено от нормативных актов. Применимость устанавливается по конкретным данным, целям, субъектам и оператору. Две обязательные галочки и cookie banner для любого сайта законом здесь не объявляются.

Уровень обязательности действует в пределах области конкретного правила. Карточка не доказывает соответствие сайта; для каждого применимого ID нужны проверка и свидетельство.
