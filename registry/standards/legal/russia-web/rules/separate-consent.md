# Отдельное согласие на обработку

## Коротко

Когда обработка основана на согласии, оно оформляется отдельно от других подтверждаемых документов и условий.

## Плохо

```html
<label><input type="checkbox" checked required>Согласен с офертой, политикой, обработкой данных и рекламой</label>
```

## Хорошо

```html
<p><a href="/privacy/">Политика обработки данных</a></p>
<label><input type="checkbox" name="pd_consent" required>
  Даю согласие на обработку данных для ответа на обращение
  согласно <a href="/consents/feedback/">отдельному тексту согласия</a>.
</label>
```

## Почему

Статья 9 требует конкретного, информированного и однозначного согласия и его отдельного оформления. Checkbox является одним из вариантов доказуемого действия, а не единственным допустимым способом.

## Когда применять

Только для целей, где выбрано согласие и допустима такая форма. Когда закон требует письменную форму, обычная галочка сама по себе ее не заменяет.

### Требования

- Не объединяйте согласие с офертой, политикой или рекламой одним флагом. Текст и версия отдельного согласия доступны до действия.
- Не устанавливайте согласие заранее и не выводите его из молчания. Сервер проверяет явный выбор и связывает его с нужной целью и версией текста.
- Опишите оператора, цель, данные, действия, условия/срок и порядок отзыва в применимом объеме. Требования письменной формы проверяются отдельно.
- Пример является фрагментом формы, а не готовым юридическим текстом; required оправдан только при необходимости этого основания для данной операции.

## Как проверить

- Проверьте отправку без отметки, подмену версии текста и отключенный JavaScript; сервер не создает согласие автоматически.
- Проверьте раздельность согласия, договора и необязательной рекламы на desktop/mobile.

## Человек

Определяет необходимость согласия, применимую форму и утверждает отдельный текст для конкретной цели.

## Агент

Реализует отдельное действие без предустановки; проверяет серверную валидацию, версию текста и отправку без JavaScript.
