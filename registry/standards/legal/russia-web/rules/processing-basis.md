# Правовое основание обработки данных

## Коротко

Для каждой формы и цели обработки определите правовое основание до сбора данных.

## Плохо

```text
Все формы требуют две галочки; цели, состав данных и основание не определены.
```

## Хорошо

```text
Форма заказа: необходимые для договора данные → применимое основание статьи 6.
Рекламная подписка: отдельная цель и предварительное согласие.
Политика доступна рядом с формой независимо от выбранного основания.
```

## Почему

152-ФЗ предусматривает несколько оснований обработки. Согласие не является универсальным обязательным основанием каждой формы; наличие галочки само по себе не делает обработку законной.

## Когда применять

Для операторов и обработки, подпадающих под право РФ. Выбор основания и специальных требований фиксирует ответственный за персональные данные с юридической проверкой при необходимости.

### Требования

- Ведите матрицу: форма/endpoint, цель, категории субъектов и данных, основание со статьей, обязательность полей, получатели и срок хранения.
- Используйте договорное основание только для данных и действий, действительно необходимых для договора или его заключения по инициативе субъекта. Реклама и посторонние цели оцениваются отдельно.
- Если основание — согласие, примените отдельное оформление и доказуемое действие. Специальные категории, биометрия, несовершеннолетние и отраслевые случаи требуют отдельной проверки.
- Нельзя объявлять две обязательные галочки законом для всех форм. Подтверждение ознакомления с политикой является возможным решением интерфейса, а не заменой основания.

## Как проверить

- Сверьте все публичные формы, API и виджеты с матрицей целей и оснований.
- Проверьте, что отказ от необязательной рекламы не блокирует самостоятельную основную услугу.

## Человек

Ответственный оператора определяет цель и правовое основание каждой операции; спорные случаи передает юристу.

## Агент

Составляет карту фактических форм и потоков, проверяет минимальность полей и техническое соответствие утвержденной матрице.
