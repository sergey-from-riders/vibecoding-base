# Навигационные ссылки и достижимость страниц

## Коротко

Значимые публичные страницы доступны через обычные ссылки с href и понятным названием.

## Плохо

```html
<span onclick="openCategory()">Каталог</span>
```

## Хорошо

```html
<a href="/catalog/">Каталог инструментов</a>
```

## Почему

Ссылка обеспечивает адресуемость, стандартную навигацию и обнаружение URL роботом. Наличие страницы только в sitemap не решает пользовательскую навигацию.

## Когда применять

Для меню, категорий, хлебных крошек, связанных материалов и пагинации. Кнопка используется для действия, не являющегося переходом к ресурсу.

### Требования

- Используйте a с разрешимым href. Клиентский роутер сохраняет рабочий URL при прямом открытии и стандартные действия ссылки.
- Текст или доступное имя описывает цель. Пустая иконка-ссылка имеет доступное имя; generic «сюда» не является основным шаблоном навигации.
- Значимые страницы достижимы из навигации или контекстных ссылок. Родительский каталог остается ссылкой при наличии подменю.

## Как проверить

- Обойдите сайт от главной и сравните достижимые URL с индексируемым набором.
- Проверьте Enter, новую вкладку, прямой запрос и отсутствие href="#" для содержательных страниц.

## Человек

Определяет важные разделы и понятные названия переходов.

## Агент

Строит доступные ссылки с href, проверяет обход от главной, прямые URL, Enter и новую вкладку.
