# Заголовок страницы title

## Коротко

У публичной HTML-страницы есть содержательный title, соответствующий ее назначению и языку.

## Плохо

```html
<title>Главная — Главная — Купить дешево купить</title>
```

## Хорошо

```html
<title>Аккумуляторная дрель D18 — Каталог Пример</title>
```

## Почему

Title помогает идентифицировать страницу. Поисковая система может сформировать другой заголовок результата; тег не гарантирует точный вид выдачи.

## Когда применять

Для публичных индексируемых HTML-страниц. Внутренние приложения также должны иметь понятные названия страниц, но SEO-индексация им не обязательна.

### Требования

- Профиль требует один title в head; шаблон заполняется из актуального содержимого без заглушек и неэкранированного пользовательского HTML.
- Разные по смыслу страницы имеют различимые названия. Для серии пагинации одинаковые title допустимы; добавление номера является решением проекта.
- Используйте краткое описание предмета страницы и при необходимости название сайта. Лимит 60 символов не является универсальным требованием Google; проверяйте читаемость и отображение.

## Как проверить

Техническая проверка доставки PR. Не сливать.

- Проверьте исходный и итоговый HTML главной, категории, карточки, статьи, пагинации и 404.
- Найдите пустые title, дубли разных сущностей, неверный язык и устаревшие значения после клиентской навигации.

## Человек

Утверждает понятные названия и редакционный шаблон для типов страниц.

## Агент

Проверяет один title в head, фактические значения, язык, экранирование и клиентскую навигацию.
