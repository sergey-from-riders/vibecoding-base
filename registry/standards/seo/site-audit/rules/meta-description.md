# Описание страницы meta description

## Коротко

Описание кратко и достоверно передает содержание индексируемой страницы.

## Плохо

```html
<meta name="description" content="Купить купить дешево лучший сайт">
```

## Хорошо

```html
<meta name="description" content="Условия доставки: доступные регионы, сроки, стоимость и порядок получения заказа.">
```

## Почему

Google может использовать описание для сниппета, но выбирает текст и из содержимого страницы. Отдельного универсального лимита 160 символов нет.

## Когда применять

Для страниц, которым полезно управляемое описание. При большом каталоге допустимы проверяемые шаблоны из фактических свойств.

### Требования

- Описание соответствует видимому содержанию и языку; не содержит фиктивных скидок, недоступных услуг или набора ключевых слов.
- Различайте существенные страницы; массовые одинаковые описания и пустые шаблонные переменные являются дефектом профиля.
- Экранируйте значение атрибута; не превращайте ручное описание в возможность HTML-инъекции. Контроль длины является редакционным бюджетом, а не гарантией вида сниппета.

## Как проверить

- Проверьте description в итоговом HTML и после смены маршрута.
- Сверьте выборку описаний с фактическими ценами, условиями и содержанием страницы.

## Человек

Проверяет достоверность описания и соответствие предложению на странице.

## Агент

Проверяет наличие, язык, экранирование, дубли и обновление description после навигации.
