# Публичный сайт с обработкой данных в РФ

Профиль для приемки публичного сайта: содержание, навигация, поиск, формы, SEO, эксплуатация и применимые требования к персональным данным. Фиксирует маршрут выбора правил; не подтверждает готовность конкретного сайта или юридическое соответствие оператора.

## Базовый состав

| Область | Модуль | Условие |
| --- | --- | --- |
| Границы, контракты, готовность | [framework/lifecycle](../standards/framework/lifecycle/standard.md) | Для всего проекта |
| SEO и публичные страницы | [seo/site-audit](../standards/seo/site-audit/standard.md) | Для индексируемой публичной части; отдельные правила имеют свои условия |
| Навигация, поиск, формы | [ui/admin-interface](../standards/ui/admin-interface/standard.md) | Выбрать подходящие ID; редакторские черновики не обязательны каждому сайту |
| Персональные данные РФ | [legal/russia-web](../standards/legal/russia-web/standard.md) | После определения юрисдикции, оператора, целей и потоков данных |
| Безопасность | [security/no-secrets](../standards/security/no-secrets/standard.md) | По угрозам и фактическим функциям сайта |
| Выпуск и восстановление | [delivery/release](../standards/delivery/release/standard.md) | По выбранной модели эксплуатации |
| Наблюдаемость | [observability/three-signals](../standards/observability/three-signals/standard.md) | Для поддерживаемого приложения и критических интеграций |

Выберите языковые и платформенные правила по [карте базовых соглашений](../../docs/language-baselines.md). Для статического информационного сайта не требуются база данных, очередь, платежи и сложная система ролей только из-за наличия этого профиля.

## Минимальные результаты приемки

1. Матрица типов страниц: реальные URL, ожидаемый статус и индексирование, применимые правила и свидетельства. Основа — [шаблон приемки сайта](../../templates/site-acceptance.md).
2. Рабочие родительские ссылки меню, доступное раскрытие, определенная модель поиска и проверка основных форм на сервере.
3. Для обработки данных — [матрица форм и интеграций](../../templates/ru-data-processing-matrix.md), фактическая политика, отдельные согласия там, где они нужны, и проверка сетевых запросов до/после выбора.
4. Проверенные прямые URL, метаданные, favicon, robots, canonical, sitemap и мобильное содержание на production после релиза.
5. Зафиксированная ревизия приложения, точный commit корпуса, результаты проверок, исключения, владелец отката и порядок устранения блокирующих дефектов.

## Границы

Юридическая применимость определяется конкретным оператором. Баннер cookies и число checkbox не заменяют эту работу. SEO-профиль не гарантирует индексирование или позиции. Предложения поиска и fuzzy matching включаются только после определения данных, прав и качества выдачи.

Для интернет-магазина дополнительно нужны платежный, заказный и потребительский контракты. Этот профиль не заявляет полное покрытие законодательства о продаже товаров, кассах, маркировке, лицензировании или отраслевых обязанностях.
