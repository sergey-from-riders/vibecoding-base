## Публикация

Перед слиянием импорт проверяется на точном Git-кандидате. После слияния требуется проверить SHA публичной редакции, страницы, изображения и Markdown на одном снимке. Публичный результат фиксируется в описании принятого изменения с SHA и отдельными свидетельствами; локальная проверка сама по себе не означает публикацию.

## Границы
