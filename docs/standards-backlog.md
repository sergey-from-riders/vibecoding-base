# Состояние содержательных доработок

## Закрыто в редакции от 13 ноября 2026 года

Все 139 оставшихся правил [исходного аудита](audit-2026-11-13/index.md) переписаны с учетом замечаний. Исправления находятся в нормативных статьях: условия применения, границы, источники, сравнимые примеры и наблюдаемая приемка. Перечень по каждому ID находится в [реестре редакции](revision-2026-11-13.md).

Добавлены 70 правил: языки, фреймворки, безопасность, навигация/поиск, SEO и обработка персональных данных для РФ. Предыдущая очередь тем про concurrency, платежи, интеграции, интерфейсы и эксплуатацию не остается перечнем отложенных редакционных правок.

Закрытие замечания в документации не означает, что проект уже прошел соответствующий сценарий. Исторические оценки исходного текста не пересчитаны задним числом.

## Оставшиеся задачи с отдельным критерием завершения

| Область | Следующий результат | Критерий завершения |
| --- | --- | --- |
| Проверки потребителей | Выполненные сценарии на фактическом приложении | Версия, вход, ожидаемый и фактический результат, свидетельство; fail/blocked/not-run различимы |
| ASVS / SSDF / OSPS | Выбранный полный профиль применимых контролей | Матрица версионных control IDs и реальные свидетельства, без вывода о compliance из отдельных статей |
| Языки вне текущего состава | Новые профили при появлении потребителя | Первоисточник, версия, naming/type/module/toolchain baseline и минимальная исполняемая проверка |
| Правовые операции конкретного сайта | Заполненная матрица данных, оснований и обработчиков | Подтвержденные фактические потоки, документы, сроки, учет согласий и применимые процедуры |
| Сопровождение источников | Повторное ревью при изменении технологии или закона | Изменены затронутые правила и reviewed_at; записаны несовместимость и переход |

Эти задачи не возвращают исправленные формулировки в статус чернового аудита. Они обозначают границы применения и следующую проверку результата. Свидетельства публикации и проверки текущей версии описаны [отдельно](publication-status.md).
