# Даты первой публикации

Этот документ описывает происхождение уже записанных дат. Структурная миграция 13 ноября 2026 года сохраняет метаданные правил без изменения и не проводит повторную проверку исторических публикаций.

## Исходная запись

111 русских атомарных правил имеют `published_at: "2026-11-09"`. В прежней документации основанием указаны выпуск PR #5 и проверка публичной редакции `4880e8b4372c96001c2e052be28b68a95d31252b` на eval.su в этот день. Дата относится к русскому материалу справочника, а не к первой версии англоязычного модуля.

Еще 31 материал имеет дату `2026-11-11`. Эти значения перенесены без массовой замены датой миграции. Историческое описание доступно в [исходной редакции](https://github.com/sergey-from-riders/vibecoding-base/blob/613500afd8eca5143b4094f6f5cd48e67844f8ff/docs/publication-dates.md).

## Дальнейшее сопровождение

`published_at` сохраняет подтвержденную дату первой публикации. Если обнаружена ошибка, исправление должно содержать основание в истории изменения. Неизвестную дату нельзя заменять текущим днем.

`reviewed_at` обозначает содержательную проверку, дата изменения получается из Git, а момент синхронизации относится к принятому снимку у потребителя. Эти даты показывают разные события и не подменяют друг друга.

Подробности формата: [контракт контента](content-contract.md). Порядок изменений: [версии](standards-versioning.md).
