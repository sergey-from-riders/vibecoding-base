# Публикация редакции 212 правил

Редакция от 13 ноября 2026 года содержит 212 правил, 19 разделов и 26 модулей. При подготовке присланного архива автор располагал только чтением GitHub; на этапе принятия проверены запись в GitHub и штатная синхронизация eval.su. Прежнее ограничение больше не является блокером.

## Источник и публичная версия

Оригиналы — правила Markdown в принятой ветке main. Сайт получает проверенный снимок одного commit, хранит его в Redis и сохраняет исправные версии на диске. Неверный кандидат не заменяет рабочий снимок. Код приложения и проверки импорта находятся в репозитории eval.su.

- [Публичный справочник](https://eval.su/standards/).
- [Точный commit текущей публичной версии](https://eval.su/standards/version/).
- [Полный Markdown в порядке новых публикаций](https://eval.su/standards/export/?scope=all&sort=newest).
- [Интеграционное ревью](integration-review-2026-11-13.md): дополнительные исправления, выполненные проверки и ограничения.

Merge и фактическая публичная приемка фиксируются в PR выпуска. Публичный version endpoint и экспорт показывают примененную версию независимо от более поздних редакций этого документа. Разрешение на публикацию получено; ручной ввод текстов в сайт не требуется.

## Проверка выпуска

Штатный импортер должен принять 212 правил и 19 разделов из одного commit. После синхронизации проверяются прямые страницы, выгрузки правила/раздела/корпуса, порядок по датам, редиректы старых адресов, индексирование и шесть иллюстраций. Выгрузка сравнивается с текстом этой версии, а не только со счетчиком материалов.

В браузере отдельно проверяются поиск, фильтры, копирование, реальное скачивание и ширина 320/390 px. Статьи о навигации и fuzzy search описывают требования для потребителя; их публикация сама по себе не меняет код меню и поиска eval.su.
