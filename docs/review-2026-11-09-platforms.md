# Критический пересмотр справочника

- Названия-действия заменены техническими терминами; инструкции остались в объяснениях. ID и ссылки сохранены.
- UI/UX стал подразделом Frontend: удалено дублирование навигации, существующие адреса работают.
- Деньги отделены от времени: integer допустим при доказанном диапазоне, bigint не безграничен, numeric нужен для дробных расчётов. Валюта, масштаб, JSON и округление описаны явно.
- CMS, CRM, фреймворки и библиотеки различаются по назначению. Правила платформ не подменяют общие правила API, доступа и данных.
- Form Request/DTO не объявлены авторизацией; afterCommit/on_commit не объявлены гарантией доставки.
- Человек отвечает за цель, бизнес-решения и пределы доступа; агент — за исследование, реализацию и фактическую проверку. Перечни проверок остаются рекомендациями, а не заявлением о наличии CI.
- GitHub Markdown остаётся источником, Redis — рабочей копией с восстановлением.

Новые примеры сверены с приведённой официальной документацией. Это минимальные фрагменты для конкретного API; не заявляется запуск Laravel, Bitrix, Django и остальных платформ в CI этого реестра. Проверка реестра подтверждает структуру, связи и воспроизводимость Markdown.
