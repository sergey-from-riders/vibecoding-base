# Исключение из принятого требования

Заполняется при осознанном отступлении от требования, которое применимо к проекту. Не используется для сокрытия неизвестного результата проверки.

| Поле | Значение |
| --- | --- |
| Проект / версия | <значение> |
| ID требования и SHA корпуса | <значения> |
| Причина отступления | <конкретное ограничение> |
| Наблюдаемый риск | <сценарий и последствия> |
| Компенсирующая мера | <проверяемая мера> |
| Ответственный | <фактический владелец> |
| Срок или условие пересмотра | <значение> |
| План устранения | <шаги/ссылка> |
| Решение уполномоченного лица | <зафиксированное решение или ожидается> |

Не подставляйте выдуманное одобрение. Исключение должно оставаться видимым в матрице приемки; при изменении существенных условий его пересматривают.
