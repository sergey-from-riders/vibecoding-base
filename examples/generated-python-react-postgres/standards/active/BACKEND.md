## Async I/O

### Коротко

В async-коде используйте асинхронный ввод-вывод или выносите блокирующую работу.

### Плохо

```python
async def handler():
    time.sleep(5)
```

### Хорошо

```python
async def handler():
    await asyncio.sleep(5)
```

### Почему

Один блокирующий вызов может задержать другие запросы процесса.

### Когда применять

Для Python asyncio. CPU-задачи обычно требуют процессов или выделенного worker; to_thread не делает произвольную CPU-работу параллельной в обычной сборке с GIL.

### Как проверить

- Параллельный лёгкий запрос остаётся отзывчивым?

### Человек

Определяет требования к задержке и пропускной способности.

### Агент

Реализует правило в коде сервиса и проверяет ошибку, отмену и граничные входные данные.

Контроль результата:

- Параллельный лёгкий запрос остаётся отзывчивым?

## Валидация типов

### Коротко

Типы помогают разработчику, а проверка входа защищает работающую систему.

### Плохо

```text
quantity = payload["quantity"]
charge(quantity * price)
```

### Хорошо

```text
quantity = validated_request.quantity
# Целое число в разрешённом диапазоне.
```

### Почему

Аннотация типа сама по себе не проверяет входящий JSON.

### Когда применять

Для Python/FastAPI подходят модели Pydantic; конкретная версия фиксируется зависимостями проекта.

### Как проверить

- Проверьте строку, отрицательное число и слишком большое значение.

### Человек

Определяет допустимые значения и поведение при неверном вводе.

### Агент

Реализует правило в коде сервиса и проверяет ошибку, отмену и граничные входные данные.

Контроль результата:

- Проверьте строку, отрицательное число и слишком большое значение.

## Читаемость кода

### Коротко

Разделяйте независимые обязанности и сохраняйте объяснения неочевидных решений.

### Плохо

```text
Удалить полезные комментарии, чтобы уложиться в 5%.
```

### Хорошо

```text
Разделить независимые задачи.
Оставить комментарий о причине ограничения.
```

### Почему

Формальный лимит строк не доказывает простоту программы.

### Когда применять

Порог сложности может быть локальным сигналом ревью. Размер файла и доля комментариев не универсальные стандарты.

### Как проверить

- Можно ли назвать одну ответственность модуля и объяснить его зависимости?

### Человек

### Агент
